# Календарь задач


Мобильное приложение для Android, представляющее собой удобный планировщик задач с календарным представлением. Приложение позволяет создавать задачи на конкретные даты и время, отслеживать их выполнение и получать своевременные локальные напоминания.



## Функции приложения



* **Календарь**: Главный экран приложения — интерактивная сетка дней текущего месяца с возможностью переключения между месяцами.
* **Индикация задач**: Дни, на которые запланированы задачи, отмечаются визуальными индикаторами (точками) прямо в календаре.
* **Что можно делать с задачами:**:
  * Создание задач с указанием названия, описания, даты и времени.
  * Редактирование существующих задач.
  * Удаление задач свайпом (влево/вправо) с подтверждением действия.

* **Валидация данных**: Запрет на сохранение задач без названия, а также задач с датой/временем в прошлом.

* **Уведомления и напоминания**: Приложение отправляет push-уведомления в заданное время, даже если оно свернуто или экран устройства заблокирован. При удалении задачи запланированное уведомление отменяется.

* **Локальное хранение**: Все данные сохраняются на устройстве пользователя благодаря БД на SQLite и работе через Room.

## Требования для сборки



* **Android Studio**: Актуальная стабильная версия (рекомендуется Iguana, Jellyfish или новее).

* **JDK**: Java 17 (необходима для корректной работы Android Gradle Plugin 8.x+).

* **Минимальная версия Android (minSdk)**: API 26 (Android 8.0).

* **Целевая версия (targetSdk)**: API 34+ (Android 14).
